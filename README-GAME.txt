STANCE CRIMEA — BEETLE BRAWL v0.1.6
Актуальная графическая база SCENE v2.8 (v2.7 без звездопада).

Запуск: index.html или game-beetle-v0.1.6-play.html (автономный, все ресурсы встроены). Для общего TOP 10 нужен PHP; см. ../README-INTEGRATION.md. Не перезаписывать records.txt действующего сайта.

Управление ПК: влево/вправо, пробел, Esc. Мобильные устройства: невидимые зоны всего экрана 25/25/50 — влево/вправо/удар; мультитач. Арена 1664×936, 16:9. Начальный экран, информация, пауза, GAME OVER, имя, TOP 10, выход на сайт сохранены.

Механика: 5 жизней, +100 за одного побеждённого врага. Четыре типа, движение к белому Beetle, PUNCH FX, распад после касания. Случайная скорость перемещения растёт, FPS бега неизменен. Предметы: один шанс 10% на побеждённого противника, равные веса, 5 секунд игрового времени, автоматический подбор. Бутылка/сигареты −1, яблоко/банан +1 до 5. При касании Beetle выпадения нет. Параметры config.js.

Архитектура: engine.js — симуляция, game.js — рендер и управление, game.css/index.html — интерфейс, records.js/records.php — рейтинг, assets/items — четыре новых PNG, game-data.js — встроенные ресурсы. Пересборка: python build.py. Тесты: node tests/engine.test.cjs; node tests/variation.test.cjs; node tests/items.test.cjs; node tests/records.test.cjs.

Утверждённые ресурсы неизменны. Старые кнопки сохранены в assets/hud/mobile, но не используются. Звука нет. Реальные смартфоны и хостинг не тестировались. Прежние отчёты в qa относятся к соответствующим историческим версиям.

Touchfix: отключены нативные выделение и подсветка касаний, обновлён спрайт банана с коричневым хвостиком. Игровые настройки не изменены. Автономный HTML пересобран.

v0.1.6: удар уничтожает все лежащие предметы в зоне удара (punchRange и punchBackTolerance), без изменения жизней и очков, с существующим эффектом удара. При замахе подбор предмета в зоне удара отложен до попадания. Загрузочная заставка — статическая композиция существующей сцены, cover на весь viewport; игровое поле сохраняет 16:9. Автономный HTML содержит фон.

Экран информации: мобильный шрифт увеличен с 4 до 5 пиксельных единиц (+25%), перенос строк адаптирован, перед подсказкой управления оставлен пустой интервал; подсказка скрыта на ПК.
