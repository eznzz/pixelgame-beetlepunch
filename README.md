# BEETLE BRAWL — STANCE CRIMEA

Версия v0.1.14, самостоятельная статическая сборка для GitHub Pages. Игровая механика, графика и синтез звука сохранены.

## Запуск

```sh
python -m http.server 8000
```

Открыть http://localhost:8000/ . На GitHub: Settings → Pages → Deploy from a branch → main → / (root).

## Разработка

- `config.js` — баланс, предметы и аудионастройки.
- `engine.js` — симуляция.
- `game.js` — управление, Canvas, интерфейс.
- `audio.js` — согласованный синтез; `assets/audio/` — экспорт WAV.
- `assets/` — графика и ресурсы.
- `ENGINE-NOTES.md` — исторические технические заметки.

После изменения ресурсов или кода: `python build.py`. Тесты: `node --test tests/*.test.cjs`.

GitHub Pages не выполняет PHP. В этой сборке рекорды сохраняются локально в браузере; переход на основной сайт удалён. Общий рейтинг требует отдельного API. Лицензия проекта не назначена.

## Обновление управления v0.1.15

Сенсорные зоны: 0–20% влево, 20–40% вправо, 40–100% удар. Пиксельная кнопка рядом со звуком переключает полноэкранный режим через Fullscreen API. В iframe необходимо разрешение `allowfullscreen` / `allow="fullscreen"`; на неподдерживаемых устройствах кнопка остаётся видимой и объясняет ограничение браузера; внутри iframe можно открыть игру отдельно. Игровая сцена сохраняет пропорции 16:9.

Исправление: сенсорное управление определяет действие по координате касания относительно полной ширины области, независимо от CSS-сетки.

## v0.1.17 — энергетик

Синяя банка: +15% к базовой скорости перемещения (395 → 454.25 px/s) на 15 секунд игрового времени. Анимация, удар, жизни и скорость врагов не меняются. Повторный подбор обновляет таймер без суммирования. При паузе таймер заморожен, при новой партии сбрасывается. Пятый предмет имеет вес 1; общий шанс выпадения 10%, время на земле 5 секунд. Уничтожается ударом как остальные предметы. Настройки: `energyDuration`, `energySpeedBonus`.
