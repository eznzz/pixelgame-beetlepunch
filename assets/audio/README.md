# BEETLE BRAWL — audio archive v0.1.14

Original procedural audio exported from the game's audio.js at 48 kHz, stereo, signed 16-bit PCM WAV. No third-party samples or downloads used by the synthesizer. Music is exported as a complete loop; effects include the playback gain envelope, before the game volume controls. swing.wav is the approved heavy preset; wide and double are alternatives. Sample-rate and browser resampling differences may affect exact playback. The game continues using its unchanged local synthesizer; these files are archival assets, not a replacement playback engine.

Regenerate from this folder: `node export.cjs .`.
